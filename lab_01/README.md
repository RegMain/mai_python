# Лабораторная работа №1

**Задача**: написать CLI утилиту для вычисления значения заданного выражения и перевода из одних единиц в другие на Python

**Функционал**:
- *Калькулятор* (calc):
	- операторы +, -, /, //, % и *
	- поддержка унарного + и -
	- поддержка скобок
	- поддержка вещественной арифметики в рамках Python
	- поддержка десятичных запятой и точки
	- игнорирование пробелов
	- история успешных вычислений сохраняется в history.json
	- токенизация данного выражения
	- валидация данного выражения на предмет невалидных скобок, деления на ноль, неизвестных символов и т.д.


- *Конвертер* (convert):
	- поддержка перевода между kg, g (Mass); m, mm, cm, km (Distance); c, f, k (Temperature)
	- перевод между различными единицами запрещён
	- по умолчанию используется файл converter.json. Пользователь может указывать при помощи параметра --config собственный конфигурационный файл для перевода между различными величинами. Синтаксис файла приведён ниже в разделе **Дополнения**.
	- в конфигурационном файле можноуказать минимальное и максимальное значение величины, если таковые имеются
	- конфигурационный файл поддерживает любые корректные формулы для перевода между величинами на случай, если зависимость нелинейная.

**Принцип работы**:
- *Калькулятор*: используется посимвольная токенизация с разделением на различные типы токенов (оператор, операнд или скобка). Далее идёт валидация на все случаи жизни: неправильные скобки, деление на ноль, отсутствие операнда или оператора, неправильно записанное число и т.д. После этого при помощи алгоритма Дейкстры (shunting yard) набор токенов из инфиксной формы преобразуется в постфиксную (обратная польская нотация), при помощи которой и получается итоговый ответ.
- *Конвертер*: для начала определяются типы обеих величин (например, температура, Temperature) при помощи данного конфигурационного файла. После чего, при возможности перевода, первая величина сначала переводится в стандартную единицу типа (например, из СИ, или указанную пользователем), после чего уже в необходимую единицу. Все выражения для этого берутся из конфигурации. Минус данного подхода в том, что некоторые системы, например, имперская, могут быть плохо совместимы с другими, из-за чего будет некоторая погрешность из-за промежуточных вычислений (даже если её быть не должно)

**Инструкция**: запуск (из виртуального окружения):
`python -m toolkit (calc, convert)`
При запуске без аргументов программа выдаст справку об использовании (`--help`)
Пример использования:
`python -m toolkit calc "2+2"`
`python -m toolkit 1000 --from m --to km`

**Дополнения**:

Синтаксис конфигурационного файла для конвертера:
```json
{
	"unit": {
		"type": "Type",
		"to_standart_expression": "5 * x + 3",
		"from_standart_expression": "(x - 3) / 5",
		"min_value": min_value,
		"max_value": max_value
	},
	...
}
```
`to_standart_expression` - из единицы в стандартную
`from_standart_expression` - из стандартной в единицу
`min_value` и `max_value` - необязательные поля, в них для всех элементов типа пишется одно значение: мин./макс. значение (например, 0 Кельвинов)
Пример можно найти в файле src/toolkit/converter.json
Указать свой конфигурационный файл можно при помощи аргумента `--config `.
